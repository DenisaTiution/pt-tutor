# Tabu — Jogo de Palavras em Português

Um PWA simples e limpo para jogar Tabu (jogo de palavras) em Português.

## Funcionalidades

- 🎮 **Jogar Tabu** — Mostre a palavra, os seus alunos explicam sem usar as 2 palavras proibidas
- ➕ **Criar Cartas** — Adicione as suas próprias palavras e palavras proibidas
- 📋 **Gerir Cartas** — Edite ou elimine as suas cartas
- 💾 **Dados Locais** — Tudo guardado no seu dispositivo
- 📱 **PWA** — Instale no telemóvel como uma app
- 🔄 **Offline** — Funciona sem internet depois do primeiro carregamento

## Como Usar

1. **Abrir a app:**
   - Abra `index.html` no browser
   - Ou aceda via http://localhost:8000 (se tiver um servidor local)

2. **Carregar Dados de Exemplo:**
   - Clique em "⬇ Carregar Dados de Exemplo"
   - 8 cartas com palavras A2/B1 em Português

3. **Jogar:**
   - Clique em "▶ Jogar Tabu"
   - Mostre cada palavra aos seus alunos
   - Eles explicam sem usar as 2 palavras proibidas
   - Clique "✓ Acertou" ou "→ Saltar"

4. **Criar as Suas Cartas:**
   - Clique em "+ Nova Carta"
   - Preencha a palavra e 2 palavras proibidas
   - Clique "Guardar Carta"

5. **Instalar no Telemóvel:**
   - Abra a app no browser do telemóvel
   - Menu → "Add to Home Screen" / "Adicionar ao ecrã principal"
   - Funciona offline!

## Dados

Todos os dados ficam no seu dispositivo. Nenhuma informação é enviada para a internet.

## Desenvolvido para Aulas de Português

Perfect para treinar vocabulário e expressão oral com alunos A2/B1.
